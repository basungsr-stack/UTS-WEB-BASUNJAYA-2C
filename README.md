## Fitur
- HTML5 semantik: header, nav, main, section, article, aside, footer
- Bootstrap 5 + `css/style.css` kustom, responsif desktop/tablet/mobile
- Mode gelap (tersimpan di browser)
- Filter kategori dan pencarian proyek

- Validasi form kontak (nama, email, pesan)
